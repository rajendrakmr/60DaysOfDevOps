## 📌 About This Challenge

Welcome to my **60 Days of DevOps Challenge!**

The goal of this challenge is to strengthen my practical knowledge of DevOps, Cloud Computing, Kubernetes, CI/CD, DevSecOps, Infrastructure as Code and Site Reliability Engineering.

Over the next 60 days, I will:

- Learn and implement DevOps concepts.
- Build hands-on projects and practical labs.
- Practice real-world troubleshooting scenarios.
- Automate application build and deployment processes.
- Implement security practices in CI/CD pipelines.
- Share daily technical learnings on LinkedIn.

**My approach: Learn → Implement → Document → Share.**

---

## 🎯 Learning Objectives

- Strengthen Linux administration and shell scripting.
- Understand Git and GitHub workflows.
- Master Docker and containerization.
- Develop Kubernetes administration and troubleshooting skills.
- Build automated CI/CD pipelines using GitHub Actions.
- Implement DevSecOps security tools.
- Gain practical AWS cloud experience.
- Automate infrastructure using Terraform.
- Understand monitoring, observability and SRE concepts.
